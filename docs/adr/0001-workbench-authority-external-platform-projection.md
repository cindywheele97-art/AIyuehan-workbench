# AIyuehan Workbench is authority and the external platform is projection

An External Work Platform may supply useful Issues, Agents, Squads and collaboration, while an External Runtime Provider may supply execution capacity; neither proves the typed Artifact, Evidence, Approval and Stage-promotion semantics required by AIyuehan Workbench.

AIyuehan Workbench therefore owns Workflow Runs, Artifacts, Evidence, Gate Decisions, Approvals, Execution Grants, and audit history. External Work Platforms and External Runtime Providers supply replaceable collaboration, Projection and execution capabilities. External Issue status, comments, role text, or task completion never become governance facts.

Consequences: Projection may lag or fail without changing Workbench Authority; all external mutations require durable intent and reconciliation; direct provider database access is forbidden. Rejected alternatives were treating an External Work Platform's status as canonical or rebuilding a provider's collaboration and runtime product inside AIyuehan Workbench. Revisit only if a qualified provider release proves equivalent typed authority semantics and migration preserves historical digests.
